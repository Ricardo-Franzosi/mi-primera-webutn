El autor

Entre la medicina, el mar y la tecnología

Esta web nació como un proyecto de aprendizaje y, al mismo tiempo, como una forma de registrar una aventura muy personal: la preparación y navegación del Atlantis hacia el Fin del Mundo.

El proyecto combina intereses que parecen lejanos pero que comparten bastante: aprender haciendo, resolver problemas concretos y dejar registro de una experiencia. El mar aporta las historias; el desarrollo web, una forma de contarlas.

La primera versión fue desarrollada como práctica de HTML y CSS para UTN. Esta edición conserva ese origen y la transforma progresivamente en una bitácora digital de viaje.
