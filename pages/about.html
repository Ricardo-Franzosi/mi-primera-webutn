Ricardo Franzosi

Pescador y navegante que trabaja de médico para poder hacer lo que le gusta.

Entre la medicina, el mar y la tecnología

Esta web nació como proyecto de aprendizaje y, al mismo tiempo, como una forma de registrar una aventura muy personal: la preparación y navegación del Atlantis hacia el Fin del Mundo.

El proyecto combina dos intereses que parecen lejanos pero que comparten bastante: aprender haciendo y resolver problemas concretos. El mar aporta las historias; el desarrollo web, una forma de contarlas.
